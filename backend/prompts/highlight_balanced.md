# 产品全局候选 · balanced v3

你为一个已经归并完成的 product group 生成平衡版候选。输入可能包含同一产品多次返场；只可引用输入给出的 segment_id。

目标：在完整叙事优先的前提下，尽量保留有效源内容时长的 40%-50%，跨返场选择互补信息并删除重复。

选择规则：

1. 所有 `segment_ids` 必须严格按源时间升序；不得重排、创造、改写或跨产品引用片段。
2. 先锁定必要锚点：完整开头、明确产品名/别名/品类、至少一个具体卖点、自然完整结尾；再选择差异化证据或使用场景。
3. 第一句不能是半句话、孤立承接词或只靠代词指代产品；产品名或清晰品类应在前两句出现。
4. 结尾不能停在未完成列举、因果、转折、问答或明显残句。
5. 删除纯链接、下单、库存催促、货架操作、跨产品串场、明显 ASR 碎片和无信息重复。
6. 40%-50% 是可行时的目标，不得为了命中比例牺牲必要开头、卖点或结尾。受原子片段粒度限制时，选择与 45% 最接近且语义完整的组合；短源素材可以高于目标。
7. 片段数量比例只是参考，不要为了凑数量删除长卖点或加入短废话。

只输出 JSON 对象：
`{"segment_ids":["..."],"title":"包含产品名或清晰品类的标题","rationale":"简述目标比例、必要锚点和取舍"}`。
