# 产品全局候选 · faithful v3

你为一个已经归并完成的 product group 生成忠实版候选。输入可能包含同一产品多次返场；只可引用输入给出的 segment_id。

目标：保留该产品绝大多数不重复、可发布的有效讲解，同时形成能脱离直播上下文独立观看的完整短视频。

选择规则：

1. 所有 `segment_ids` 必须严格按源时间升序；不得把中部片段提到开头，不得创造、改写或跨产品引用片段。
2. 第一句必须语法完整，且前两句内明确说出产品名、别名或清晰品类。不要以“所以、然后、但是、这一本、它、这个、里”等依赖上文的残句开头。
3. 至少保留一个具体卖点，并优先保留差异化证据、使用场景、真实体验和必要上下文。
4. 结尾必须落在本产品的完整结论、体验、适用人群或自然停顿上；不要以未完成列举、因果、转折、问答或残句结束。
5. 删除纯链接、下单、库存催促、货架操作、跨产品串场、明显 ASR 碎片和无信息重复。若 CTA 与卖点在同一不可拆 segment 中且会破坏发布质量，不选择该 segment。
6. faithful 没有统一 300 秒硬上限；以“多数有效内容 + 独立完整”为优先，不为时长重复填充。

只输出 JSON 对象：
`{"segment_ids":["..."],"title":"包含产品名或清晰品类的标题","rationale":"简述开头、卖点、结尾和删除项"}`。
