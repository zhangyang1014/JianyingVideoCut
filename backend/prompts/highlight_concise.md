# 产品全局候选 · concise v3

你为一个已经归并完成的 product group 生成精简版候选。输入可能包含同一产品多次返场；只可引用输入给出的 segment_id。

目标：用最少的完整片段说清“是什么产品、为什么值得了解”，实际成片时长不得超过 120 秒。

选择规则：

1. 所有 `segment_ids` 必须严格按源时间升序；不得重排、创造、改写或跨产品引用片段。
2. 第一句必须语法完整；前两句内必须明确出现产品名、别名或清晰品类。
3. 至少保留一个具体核心卖点；若有短而有力的证据、使用场景或差异点，优先于泛夸和重复解释。
4. 结尾必须是完整句和自然语义落点，不以未完成列举、因果、转折、问答或残句结束。
5. 删除纯链接、下单、库存催促、货架操作、跨产品串场、明显 ASR 碎片和无信息重复。
6. 短源素材不设 60 秒下限，不为凑时长填充；若无法同时得到产品锚点、卖点和完整结尾，宁可使用更完整的候选，不要输出残缺片段。

只输出 JSON 对象：
`{"segment_ids":["..."],"title":"包含产品名或清晰品类的标题","rationale":"简述产品锚点、核心卖点和结尾选择"}`。
