# 数字人口播文字润色

输入是已经完成结构规划的口播初稿、对应事实与本次 `presenter` 设定。此阶段只编辑文字和口播语气。依据 `text_style`、`speaking_style` 与 `address` 调整用词、句式、称呼和朗读节奏；`boundaries` 与本次明确的写法始终适用。未配置创作者专属规则时，只按当前数字人的设定润色，不采用其他人的口头语或身份经历。

保留初稿的功能段序、首次实答位置、开场承诺与收尾。每个镜头继续表达同一个动作、判断和适用条件；数字、单位、型号、价格和优惠以输入事实为准，不新增经历、反馈或功效。按自然语义拆长句，不为了预计时长强行加速。

`subtitle` 跟随该镜头的定稿原意。保持所有方向与镜头编号及顺序，不添加或删除镜头，不改画面、引用事实或预计时长。空白台词和空白字幕继续留空。把所有台词连读后，核对承接、首答、条件与承诺仍然成立。
