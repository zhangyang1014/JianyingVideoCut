# Lina 短视频结构

## 风格卡与证据

写稿前按 `domains/goldenclip/creator_styles/active.json` 读取 Lina 当前版本的 `card.md` 和 `evidence.json`。共用分析流程见 `docs/creator-style-analysis.md`。按题材、观众主问题和目标时长选择规则，先排功能段序，再填本次资料中的事实。风格卡里的统计区分第一段与完整开场；频率是样本描述，不能变成所有选题的硬模板。`reported` 表示用户提供但本地未回查，`candidate` 表示待验证的写稿建议，不能声称已完成本地样本验证。下文的带货和制作要求不自动视为样本统计结论。换创作者要从新语料分析，不套用 Lina 规则。

## 先找到观众要解决的问题

先根据本次简报确定写作目标。指定商品带货要回答「这款为什么值得买」，比较选购要给判断尺度，做法题要交代第一步，观点题聚焦卡住的判断。结合受众和选题，确定观众眼下要解决的一件事。只交代会影响答案的学段或家庭条件。开场可以直接给判断，也可以用熟悉的一幕、承诺交付的具体办法、资料中确有的家长提问，或带条件的直接提问。第一句就切题，场景说清后进入首答。

## 指定商品的带货稿

1. 起稿前用一句话写清楚「谁在什么时候需要什么，这款商品怎么帮上忙」。把它当成全片的主要购买理由。
2. 开场让观众认出自己的需求。亮出指定商品时，紧接着说用它能怎么解决，让商品成为开场问题的首答。
3. 中段先说能支撑购买理由的共用能力，再用场景说明怎样用、能看到什么结果。跨场景前说清它们为什么一起讲，每个例子展示一个新用法、条件或结果。只留有本次资料支持、对购买理由有贡献的功能、规格和差异。
4. 观众顾虑会影响购买时，可以先提出顾虑，紧接着用可核对的卖点、演示或本次权益答复。耗材优势须有本次货盘和使用周期，竞品费用按同样用量、周期和优惠口径对照。交代会影响判断的商品、渠道、期限和权益条件。待核对的问题留给制作人员。
5. 收尾回到开场的人和场景，点清为什么值得选这款。按已核实的购买入口或活动给一个清楚的行动。

## 按题材排段落

| 家长要解决的问题 | 段落顺序 |
| --- | --- |
| 怎么开始、怎么练、怎么规划 | 说明要解决哪件事 → 给第一步或可用的总框架 → 按实际步骤演示 → 指明从哪一步开始 |
| 怎样选、什么情况适用 | 摆出使用场景和共同的选择标准 → 给首选或可操作的判断条件 → 用同一维度对照选项 → 按年龄、基础、目标或预算等有效条件给选择动作 |
| 孩子在哪儿卡住了 | 还原一幕 → 提炼可观察的卡点 → 给一个可执行的动作 → 用另一种情况、反例或一句可以照说的话补足 |
| 推介指定用品、书单或课程 | 从真实用途进入 → 交付这款怎么帮忙 → 用演示或资料说明购买理由 → 回扣同一用途并给购买动作 |
| 对一件事怎么看、一次经历说明什么 | 先说判断或呈现有反差的一幕 → 交代有依据的经过与取舍 → 用案例解释做法 → 回扣可以迁移的原则和适用条件 |

## 尽早交付，最后把问题答完

- 开场聚焦一个主问题。可以用几句交代同一场景或选择，把铺垫控制到观众刚能理解为止，接着给判断或办法。也可以直接给判断。这是制作约定，不作为原片统计结论。
- 通常争取在第 2–3 个功能段落或更早给出第一条真实答案，用一句话交付动作、判断标准或具体解释。随后解释为什么。按题材和本次问题选择位置，话题预告、编号和情绪铺垫不算实答，不为凑段号增加铺垫。
- 中段每一段推进一步，例如演示一个动作、解释一个条件、比较两种可见结果，或指明何时调整。有分层时，每支交代适合谁、先做什么、什么时候换办法。开场承诺了两件事，正文分别兑现。
- 收尾回到最初的问题，给一个当下能做的动作或回扣核心判断。涉及适用范围时把关键条件说清。互动或推广放在答案交付后，按本次任务需要使用。
- 短稿可压成「具体情境 → 第一条答案 → 一个例子或两种条件 → 眼下能做什么」。口播段落是推进单位，可由多个镜头呈现。按本次预计时长和口播节奏安排内容。

## 交稿前连读检查

- 从头到尾连读台词。逐段写清「承接了前面哪句话或哪个需求」和「本段新增的回答是什么」。带货稿再核对这个回答推进了这款商品的哪个购买理由。说不清时，调整段序、补一句简短衔接，或删掉这段。保留用户已经定稿的句子。
- 中后段优先复用开场的人物、场景和目标。新的用途、受众或比较对象只有直接支撑同一个购买理由时才展开，并在出现前交代为什么要讲它。功能清单上的信息可以留在画面或制作资料里。
- 规格讲一次，后面用例子让人看懂怎么用。同一段的台词、字幕和画面要在讲同一个卖点，画面中未出现的操作标成拟补镜头。最后核对结尾有没有兑现开场提出的问题。

## 使用资料的边界

样本用于学习段落功能和顺序。单条案例可以提供写法建议，结论的适用范围按证据说明。新稿用自己的话，选择本次资料能支持的场景与例子。第一人称用过商品、家庭经历、粉丝求助、孩子反馈或他人原话，须有明确来源和可公开的确认。假设场景和话术按举例表达。商品规格、适用年龄、用法、价格、优惠和效果以本次资料或可核对的演示为准。删去缺乏依据的卖点，用可展示的事实落地判断。
