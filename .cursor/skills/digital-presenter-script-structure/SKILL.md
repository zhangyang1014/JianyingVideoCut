# 数字人口播结构

在受众、选题与本次可用事实明确后调用。读取项目的 `presenter` 设定，先确定观众要解决的一件事，再按 `structure_style` 排功能段序，写出口播初稿与配合这些段落的镜头。未填写结构风格时，可按“切入问题或场景 → 给出答案或办法 → 用解释、例子与条件展开 → 回扣主问题”组织，按题材调整，不固定开场句式或段落数。

正文中的例子、分层和演示须推进同一个主问题；收尾兑现开场的承诺。参考片长为空时按内容安排，不为凑秒数截断台词。口播段落与镜头、字幕行分别处理。

本次受众、内容定位、结构风格与表达边界优先于默认写法。仅参考当前数字人自己的风格卡，保留其证据状态；未提供风格证据时按本次设定写，不继承其他创作者的经历、话术或统计结论。商品规格、价格、效果和个人经历须有本次资料支持。

输出沿用生产规划的方向与镜头契约，在 `structure` 中说明功能段序；写好初稿后交给 `digital-presenter-spoken-polish` 做文字与口播润色。用户已保存的原稿转分镜沿用原文，不重新执行起稿。
