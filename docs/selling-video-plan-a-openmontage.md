## 1. 目标与适用方式

建立一个独立制作项目，贯通品牌资料理解、创意策划、实拍指导、AIGC 提示词、素材回传和自动成片。用户在自己现有的 AIGC 工具中生成内容，系统保留全部创作上下文，收到素材后继续剪辑。

本方案独立运行，不依赖 GoldenClip 或另一份方案。首版通过 Codex 对话操作项目，文件夹承载资料和素材，项目看板展示进度。“一键剪辑”首版对应一次“素材已齐，开始成片”的指令；若要求图形按钮，补一个轻量本地项目页面。

首轮验证默认一个品牌、一个产品、一个主播，制作一条 30–60 秒、9:16、1080×1920 的中文视频。这些是试验范围，可在创作开始前改为实际平台要求。

## 2. 现有基础和需要补齐的部分

[OpenMontage](https://github.com/calesthio/OpenMontage) 的 [Hybrid 流程定义](https://github.com/calesthio/OpenMontage/blob/main/pipeline_defs/hybrid.yaml)包含创意、脚本、分镜、素材清单、剪辑决策与合成阶段，能够表达实拍和生成素材的组合。仓库提供项目看板及渲染相关能力；这些能力在本方案中仍须逐项实测。

本次新增的关键部分是：品牌 PPT 解析、适配用户工具的镜头提示词、外部制作任务包、长期等待素材的恢复机制、素材与分镜的绑定，以及剪映草稿适配。

实施前完整获取仓库，记录所选提交和许可证。仓库当前标注 AGPL-3.0；本方案采用独立项目方式进行验证。不要将仓库宣传中的生产可用性当作已经通过的验收结果。

## 3. 用户全流程

### 第一步：建立品牌与制作资料

用户提交品牌 PPT、产品图片、主播形象参考、已有视频，并补充发布平台、主推产品、目标人群和本次活动信息。记录其 AIGC 工具名称与支持的输入方式，以实际工具限制编写提示词。

系统读取 PPT 文本和页面画面，将图表、产品说明、品牌视觉一并纳入分析。产出品牌资料卡、商品事实表、素材目录。卖点保留 PPT 页码或资料出处，尚未确定的价格和活动时间标为待补充。

交付物：品牌资料卡、商品事实表、已有素材盘点及本片制作目标。

### 第二步：确定创意并形成制作任务包

系统根据资料和已有素材提出 2–3 个可拍摄方向，说明开场、核心卖点、叙事结构及新增素材工作量。用户选择一个方向后，生成完整文案及逐镜头分镜。

每个镜头必须同时包含：

| 内容 | 要求 |
| --- | --- |
| 镜头编号 | 固定编号，如 S01；修改镜头不随意重编号 |
| 叙事目的 | 该镜头承担的钩子、展示、解释、证明或收尾作用 |
| 画面与声音 | 主体、动作、构图、口播/旁白、字幕及音频来源 |
| 素材方式 | 已有素材、用户实拍、用户在外部生成的 AIGC |
| 实拍指导 | 景别、动作、台词、拍摄方向、需保留的动作前后余量 |
| AIGC 提示词 | 参考产品图和主播图、场景、动作、镜头运动、时长、画幅及连续性要求 |
| 剪辑要求 | 目标可用时长、切入/切出意图、声音跨镜头衔接、字幕强调与转场 |
| 备选方式 | 主镜头无法实现时，可以接受的替代镜头和必须保留的信息 |

提示词中的参考图必须指向用户实际提供的文件。对白镜头与静音补充画面分别标清，避免回传后同时播放两份人声。

同一份分镜同时导出成人可阅读的制作清单和机器可读取的数据；二者来自同一版本，不能分别修改后失去对应关系。

### 第三步：保存项目，等待用户制作

用户按任务包实拍或在外部工具生成素材。系统保存当前创意、文案、分镜、提示词和制作进度，进入“等待素材”。等待数天不算失败，也不需要保持进程运行。

首版按镜头文件夹回传，如 S02 下放多个生成版本；也允许直接选定一个文件绑定到镜头。自动匹配作为后续便利功能，匹配不确定时由用户选择。

### 第四步：接收素材并形成实际剪辑方案

系统读取文件时长、画幅、音轨、字幕与台词，并抽帧判断画面内容。对照分镜选取可用片段，记录素材版本及入点、出点。

计划中的“4 秒产品特写”必须重新测量实际可用范围。若生成了 8 秒但只有中间 3 秒可用，系统依照实际素材调整节奏；若关键动作缺失，指出具体镜头和补拍/重生成建议。不能用冻结画面、重复片段或改写卖点来掩盖必需素材缺失。

普通时长变化和多余停顿可以自动处理；影响叙事或核心信息的变化应显示给用户。确认可用的素材进入正式素材清单。

### 第五步：一次指令成片及局部修改

素材齐备后，一次指令完成选段、画面组接、音频衔接、字幕、品牌包装、配乐压低和导出。默认交付 MP4、字幕文件、剪辑计划和成片检查结果。

例如用户说“开头换第二遍口播，S03 多留一秒”，系统更新对应镜头和时间线，生成新版本，保留前一版成片。重复提交同一任务不会重复启动相同渲染。

剪映草稿为独立适配交付：从同一实际剪辑计划生成多素材轨道，不能假定 OpenMontage 已提供该能力。首轮仅承诺已实现并验证的裁剪、音频、字幕和基础叠加；复杂动效若需烘焙，必须在交付说明中标明。

## 4. 项目保存与阶段交接

以下为本方案拟新增的交接文件，实施时映射到固定版本 OpenMontage 的实际 schema，不直接假设这些是上游现成字段。

| 保存对象 | 作用 |
| --- | --- |
| 品牌资料与来源索引 | 记录商品事实、品牌风格和资料出处 |
| 创意及文案版本 | 记录选定方向、口播和修改历史 |
| 分镜表 | 镜头编号、制作提示词、声音安排、剪辑意图 |
| 外部制作清单 | 每个镜头待拍摄、待生成、已回传、需补充的状态 |
| 素材清单 | 文件指纹、版本、镜头绑定、实际时长和可用区间 |
| 实际剪辑计划 | 每条素材在源视频及成片中的位置、轨道、字幕与音量 |
| 渲染记录 | 所用分镜和素材版本、参数、产物及检查结果 |

项目阶段：资料整理 → 创意确定 → 分镜确定 → 等待素材 → 素材就绪 → 剪辑与渲染 → 成片。缺少素材可退回等待；修改分镜应标出受影响的素材和成片，不静默使用旧版本。

OpenMontage 原流程有阶段检查点和运行时限。应新增外部制作分支，持久保存“等待素材”，恢复时创建后续执行记录，不能让一个生成任务持续轮询数天。已确认的创意和分镜不因进程重启重新询问。

## 5. 实施顺序与交付

| 阶段 | 执行内容 | 阶段交付与通过条件 |
| --- | --- | --- |
| A0 基础验证 | 固定仓库版本；配置模型和渲染环境；用自有样例验证两段视频、中文字幕、旁白和补充画面混合 | 可播放样片、环境记录；确认混合素材渲染能够工作 |
| A1 创作与任务包 | 增加 PPT/资料导入、创意输出、稳定镜头编号、实拍指导和工具适配提示词 | 一份可以交给用户直接制作的任务包；分镜与提示词逐项对应 |
| A2 回传与恢复 | 实现等待状态、素材绑定、多个版本、实测可用片段、缺失镜头提示 | 关闭并重启后继续同一项目；局部回传不会触发重做整份方案 |
| A3 自动成片 | 将分镜和素材编译为上游剪辑输入；串接渲染、成片检查、局部修改 | 一次指令完成真实素材成片；第二版修改保持原始资料和前一版可追溯 |
| A4 交付完善 | 增加轻量操作入口；实现多素材剪映草稿导出适配 | 按钮操作验证；草稿在用户实际剪映版本中打开并抽查同步 |

前一阶段产物可验证后再进入下一阶段。若基础渲染无法处理实际素材组合，先解决该问题，不提前用漂亮的分镜输出宣称流程已跑通。

## 6. 完成验收

使用一份真实品牌 PPT、产品图、主播参考和 6–10 个镜头完成一次验证，其中同时包含实拍与外部 AIGC 视频。

1. 每个制作提示词都有固定镜头编号，并能追溯到原分镜。
2. 至少两个镜头存在多个版本；至少一个镜头的实际时长与计划不同，剪辑能正确处理。
3. 在等待素材时关闭项目，重新打开后保留文案、分镜和已绑定素材。
4. 必需素材齐备时，一次指令完成 MP4；缺少关键镜头时准确指出缺口。
5. 完整播放检查中文字幕、人声、产品画面、衔接和片尾，不能仅凭渲染退出成功验收。
6. 更换一个镜头可生成新成片，且其他镜头仍绑定原定素材。
7. 剪映交付须在实际软件内打开；核心剪辑顺序、画幅、时长和音画同步与 MP4 一致。

本方案的主要投入在外部素材回传、项目恢复和输出适配。优先价值是较快验证“创意到成片”的完整协作方式；独立项目和上游依赖需要长期维护。
