# B-roll 制作与验收工作流

适用于 GoldenClip 数字人口播的分镜规划、补镜、重做和素材交付。2026-11-19 本轮用户修正形成以下约定，后续执行从 [AGENTS.md](../AGENTS.md) 和 [数字人口播工作流](digital-presenter-workflow.md) 进入。最新用户要求优先，题材变化时重新确认受众与场景。

## 一、先核对实际口播

1. 读取当前项目、最新确认稿、实际母片和字幕时间码。上次对话中的母片名称与待办须和当前文件核对。
2. 用户采用完整 HeyGen 口播方案时，一次生成全稿母片，剪辑时复用同一音轨。人物出镜与 B-roll 画外音从实际音频取区间。
3. 用户更新 Lina 外观后，按名称、外观预览、可用状态与 ID 匹配。本轮指定 Lina，带数字编号的外观需逐项区分。生成前核对台词和所选身份。
4. 母片需要抽查开头、中段、结尾的口型、声音、手持物、原生字幕与水印。记录适合出镜或适合取旁白的区间。
5. 实际配音与旧分镜的顺序、措辞、规格或活动有差异时，记录具体差异和待对齐区间。先查本次商品资料，再决定字幕与画面，价格和换芯活动须匹配本次货盘。

## 二、按旁白拆镜，按场景合并生成

本轮单个 B-roll 的成片使用时长通常为 1–2 秒。整段旁白由多个短镜头连续覆盖，按含义、动作和场景切换拆分。

优先将同一段落的短镜头写进 1–2 条多镜头提示词，按家庭活动、厨房操作等场景合并生成。生成返回一条包含多个切镜的视频，后期依据实际切点取出各镜头。需要单独修正某个动作、参考产品外观、补失败镜头，或模型确实无法完成多镜头时，再逐镜头生成。

- 每个镜头表达一个可看见的动作或信息。先写台词对应的生活事件，再补道具、光线和运镜。
- 分镜表至少包含镜头 ID、对应旁白、音频入出点、画面动作、成片使用时长、素材来源、生成参数与声音要求。未取得音频时，入出点标为待对齐。
- 成片使用时长与平台生成时长分别记录。合并生成时，为整组设置模型支持的时长，并在提示词中给出镜头顺序和各段时间。单个镜头的实际入出点在回传后确定，保留原片。
- 第一帧已进入场景，动作尽早发生。短镜头围绕递杯、放书包、放水壶、按开关等一个动作展开。
- 按实际旁白停顿与语义对齐镜头。段落的画面总时长覆盖实际音频区间，检查重复、空缺、定格和动作截断。
- 同一旁白母片可以跨多个镜头连续播放。逐镜头字幕接起来应保留完整意思，并核对实际音轨。
- 一条多镜头原片可由多个分镜引用同一 asset_id，各自使用不同 start、end。按实际剪辑需要导出独立短片或连续预览，避免为每个逻辑镜头重复生成、上传相同文件。

### 合并生成的选择与验收

- 一组先固定家庭、主要人物和道具，再按时间段描述每次切镜的机位、动作和声音。明确普通硬切及每段的一个动作，控制场景和人物数量。
- 核对模型当前多镜头能力、支持时长和声音参数。2026-11-19 TapNow 列表明确标注 Wan 2.6 支持 multi-shot，其文生视频可选 5、10、15 秒；Seedance 2.0 Mini 支持 4–15 秒，本轮早期实际产出过一条 12 秒四镜头视频。执行时重新核对当前能力与报价。
- 提示词里的时间段是生成目标，实际动作、人物一致性和切点须看原片验收。按真实旁白剪辑时，可调整取段长度和切点。
- 模型单次多镜头可先试做，回传后检查漏镜、顺序、动作与声音。部分失败时保留可用镜头，按本轮授权与费用范围补做失败部分。
- 商品外形和标签需准确时，使用原图、实拍或已核实参考。本片机器接水处直接复用品牌素材。

### 本轮两条提示词方案

下列方案将七个逻辑镜头安排为两次情境视频生成，加一次已有品牌素材插入。当前七条单镜头样片仍可作为剪辑素材，这组提示词尚未提交生成。执行时先核对所选模型可用时长。

**提示词 A，家庭活动组，生成目标 6 秒，剪辑取约 4.5 秒**

```text
生成一条 9:16 竖屏、多镜头的中国家庭生活 B-roll，共 6 秒。
同一个普通城市公寓，白墙、浅色瓷砖、常见小餐桌和白色玄关鞋柜。
同一个七八岁、黑短发的中国小学生，同一个蓝色书包和浅黄色塑料小杯。
手机原相机随手拍，普通自然室内光，正常动作速度，轻微手持感。

0–2 秒，早晨餐桌旁，孩子穿灰色棉睡衣，将小杯递向画外家长，
第一帧已拿着杯子，椅背的书包、早餐碗筷同时入画。
2–4 秒，直接硬切到运动回家时的玄关，孩子已换上普通运动短袖，
把手里的水壶放到鞋柜上，换鞋凳旁有同一个蓝色书包和运动鞋。
4–6 秒，直接硬切回早晨餐桌，孩子穿第一镜的灰色睡衣，
拿起浅黄色空杯看一眼，再看向画外家长。单个动作自然完成。

三段之间用普通硬切，人物安静，嘴部无讲话动作。
只保留轻室内底声、衣物摩擦和杯壶轻碰声，无对白、无旁白、无音乐、无字幕。
出镜人物为家庭角色，Lina 口播在后期混剪时加入。
```

**提示词 B，烧水等待组，生成目标 6 秒，剪辑取约 6 秒**

```text
生成一条 9:16 竖屏、多镜头的中国家庭生活 B-roll，共 6 秒。
普通城市公寓厨房与相邻餐桌，白墙、浅色瓷砖，台面有家常碗筷、筷筒和抹布。
同一名家长只露手，同一个普通不锈钢电热水壶和白瓷杯。
手机原相机记录，普通室内光，正常动作速度，轻微手持感。

0–2 秒，厨房台面近景，家长按下电水壶开关，指示灯亮起，
第一帧手已伸向开关。动作后短暂停留，交代等待烧水。
2–4 秒，直接硬切至水烧开后的近景，家长已握壶柄并开始倾斜，
往放稳在台面的白瓷杯倒一小股水，再收住。
4–6 秒，直接硬切到餐桌上的同一只白瓷杯，杯里有极淡水汽，
家长的手在杯上方轻扇两下。背景有书包与早餐，儿童在热水操作范围外。

用硬切表达时间推进，三个镜头各完成一个动作。
只保留开关轻响、轻微烧水声、倒水声和衣袖摩擦声。
无对白、无人声、无旁白、无音乐、无字幕，人物安静做事。
```

## 三、中国有孩子家庭的生活感

本轮受众是中国有学龄孩子的家庭，按台词选择早起、运动回家、上学准备、放学、作业或亲子场景。

- 孩子在合适的镜头直接参与动作。年龄、衣着、动作与时间场景匹配，家长可从侧面、背面或手部入画。
- 用普通城市公寓的小餐厅、玄关、厨房、书桌等空间，交代白墙、瓷砖、常见鞋柜、饭桌与家具使用痕迹。
- 书包、课本、早餐碗筷、换下的运动鞋和毛巾根据情境自然出现，保持画面里的空间与用途合理。
- 摄影以手机原相机、自然室内光、正常动作速度和轻微手持感为默认。关键动作和交代场景的道具在竖屏内同时可辨。
- 固定奶油色、浅橡木、鼠尾草绿、静物居中、浅景深、慢推镜等要求可能带来广告摆拍感。只有用户认可这种风格时再指定。
- 连续镜头尽量保持孩子年龄、发型、杯子、书包与装修一致。独立生成的素材要核对连续性，必要时使用已获授权的参考图。
- 本轮 B-roll 使用生活场景角色，Lina 用作口播及画外音。儿童用水与电器操作按资料安排，热水由成人处理。

## 四、画幅与声音一起写入提示词

| 项目 | 本轮默认约定 | 验收方式 |
| --- | --- | --- |
| 画幅 | 生成参数和提示词均指定 9:16 竖屏 | 读取实际宽高、旋转与 SAR，检查主体和手部裁切 |
| 交付尺寸 | 1080×1920；试片记录原始分辨率 | 区分原生高清与低清放大 |
| 画面人物 | 自然动作，人物安静，嘴部无讲话动作 | 看完整段与抽帧 |
| 声音 | 轻室内底声、衣物和书包摩擦、杯子或水壶轻碰等 | 实际听音并检查动作同步 |
| 人声与音乐 | B-roll 内无对白、无旁白、无 BGM | 听音检查，混剪旁白单独对齐 |
| 字幕 | 后期统一制作 | 核对源片已有文字、标识及生成伪字 |

平台支持原生环境音时按本次要求生成并验收。原片静音或声音不合格时，可在剪辑中加入匹配的拟音，并明确记录为后期拟音。原片音轨中出现人声或音乐时，替换相关音轨后重新试听。仅检查 has_audio 或音量数值不足以证明声音内容符合要求。

素材是竖屏时，播放器外侧黑色留白还可能来自预览容器比例。先读媒体宽高并检查实际画面，再决定调整预览布局或重制素材。

### 可复用提示词骨架

```text
9:16 竖屏，普通手机原相机记录的中国家庭日常。
场景为【具体房间、时间、常见装修】，自然放着【与台词有关的生活物件】。
【年龄、衣着、侧背面】的孩子或家长，第一帧已在【动作开始状态】，
前两秒完成【一个动作】，动作后留可剪余量。
手机从【机位、景别】拍，让【关键动作与场景道具】同时入画。
普通自然室内光，正常动作速度，轻微手持感。
人物安静自然，只保留【具体环境音与动作声】，无对白、无旁白、无音乐、无字幕。
平台生成【实际支持的时长】，成片选用【1–2 秒有效区间】。
```

## 五、平台执行与商品一致性

1. 按镜头需求和当前可用能力选择平台，商品本体、面板、标签、滤芯与规格展示优先采用品牌资料或核实的实拍。生成画面用于合适的家庭情境和补镜。
   - 生成画面包含商品本体时，先将真实产品图上传至生成平台，并在生成参数中实际传入图片引用。提示词明确锁定机身轮廓、比例、配色、面板布局、出水口、品牌标识和标签，只调整获准的环境、机位与动作。不得只在文字中声称“参考原图”却未传入图片。
   - 图片引用与提示词不能保证完全复刻。回传后逐项核对上述外观；面板、标识、标签或规格出现变化时，改用真实素材或补做。纯家庭生活镜头不包含商品时，无需把产品图作为无关参考；交付时区分哪些画面来自参考图生成、哪些直接使用品牌原图剪辑。
2. 使用本轮用户已授权的生成范围，核对模型的最短时长、画幅、声音模式、参考图和实际费用。报价使用当次工具结果，同一设置的报价也可能有差异。
3. 试片标出所用模型、原始分辨率与生成时长。根据用户试做或成片意图选择质量，升格时沿用已认可的画面与动作方向。
4. 提交后保存平台、任务或节点 ID、项目 ID、提示词、参数和镜头对应关系。任务进行中继续跟进，用原任务查询结果，避免重复扣费。
5. 渲染完成后下载原片。平台返回的小尺寸预览只作为试看依据，编辑素材核对原始下载的分辨率和音轨。
6. 单条失败时记录状态和原因，继续处理可完成的镜头。重试前核对原任务是否终止，以及本轮授权和费用范围。

## 六、项目内可见才算完成回传

素材登记、镜头绑定与当前画面选择是三个不同步骤，均需检查。

1. 将原片、有效剪辑版和必要的连续预览登记到当前项目素材目录，读取指纹、时长、画幅、音轨与抽帧。
2. 记录来源类型与实际平台，区分 AIGC、品牌原图剪辑、实拍和来源待核对素材。后期拟音和低清放大单独说明。
3. 给每个逻辑镜头建立唯一 ID，绑定对应素材，再设置 selection.asset_id、start、end。多镜头原片可由多个镜头共用，逐项设置实际入出点；确认预览能定位到当前镜头区间。播放器若展示整条原片，检查是否需要导出独立剪辑版供预览。
4. 拆分段落时同步实际 shots、选中方向的镜头及相关绑定；旁白与字幕的段序保持连续，旧版本通过项目历史保留。
5. 通过已有 API 与存储逻辑提交，使用 expected_revision 处理并发，避免覆盖其他对话的新母片或修改。版本号按绑定镜头与角色已有最大值递增，检查导入后重新绑定的版本显示。
6. 在真实浏览器刷新工作台，确认镜头名称、当前素材、入出点与播放内容。试片需要可直接打开的整段预览时，一并生成和登记。
7. 交付用可访问的项目媒体链接或已保存文件链接，链接须实测可开。临时文件位置只作处理中间物，用户交付材料按当前保存规则持久化。

## 七、音频交接与最终验收

先分别验收单镜头、整段连续画面、带最终旁白的混剪，以及实际剪映草稿。报告当前完成到哪一层。

- 画面逐段覆盖旁白，短镜头按实际朗读节奏切换。拟音、原生声音、对白的来源及增益可核对。
- B-roll 里的环境声作为单独的现场声或效果声参与混音，在 Lina 旁白下保留合适音量。按用户要求检查 BGM 轨及导出音轨。
- 当前 production_renderer 的 voiceover 路径会提取所选旁白，并将画面导出为静音，再复合旁白。要保留 B-roll 环境音，需实际混入单独音轨并验证结果；若走现有入口需补实现，以最终文件试听为准。
- 用 ffprobe 核对时长、尺寸、SAR 与音轨，用 FFmpeg 完整解码，再在浏览器实际加载、播放和拖动。完整试听检查人声、音乐、拟音时机与截断。
- 字幕使用实际音频时间码，交接完整母片时保留对应独立 UTF-8 SRT。默认交付干净 MP4，不烧录口播字幕，也不额外叠加品牌文字；由用户最后调整字幕样式并合成。剪映草稿保留可编辑字幕轨。用户确认最终字幕样式前，不把文字固定到画面里。商品原图自带的面板、标签和规格属于画面内容，另行核对来源。画面试片或拟音素材的 has_audio 不代表已有口播或实际字幕。
- 剪映草稿由同一时间线导出，并在剪映打开检查素材在线、轨道、画幅与同步。结构校验和实际打开分别记录结果。

## 八、页面与视频一起报 500 时

本轮根因是新字段写入项目后，常驻后端仍加载旧版严格模型，触发 extra_forbidden。项目详情与媒体文件入口共用项目读取，因而一起失败。

1. 先读当前后端日志，检查 schema 校验与项目读取，再检查文件是否存在、指纹是否变化。
2. 区分磁盘上的代码、测试进程与实际监听端口的常驻进程。进程与端口存在，只证明服务在监听。
3. 对照 production_store 的兼容序列化处理。当前空 heygen_jobs、空 narration_draft、空 style_snapshot 与未知 origin 的默认值会按约定省略，真实数据与已填快照须保留。
4. 用受支持的模型和原子写入修复数据，检查修复前后语义一致。真实已填新字段需要运行兼容的后端版本，不能靠删除真实字段恢复。
5. 需重载时按现有常驻服务方式执行，并核对进行中的生成、分析和导出任务。权限拒绝时记录实际限制，在允许范围内修复，继续做真实入口验收。
6. 恢复后同时验证项目 GET、素材 Range 请求、真实工作台与视频播放。单独的 TestClient 成功只能证明当前测试进程可用。
