# 长时间轴审阅优化

## 改动

- 播放时间采用任务独立的时钟。播放器仍以动画帧更新逐字高亮，只有当前字幕订阅时间变化；工作台在切换句子、定位和操作时更新。
- 为字幕时间建立索引，当前句通过 ID 直接定位，跳转时跳过不相关的时间区间。保留重叠字幕的当前句优先规则、输入顺序、句间空隙和末句终点行为。修改时间轴后重新建立索引。
- 接缝复核用二分查找左右保留块，避免每处删除都扫描整个时间轴。乱序导入仍沿用原来的查找规则；复核顺序、试听范围和已检查标识不变。
- 跳转请求与播放进度分离。支持不足半秒的词间跳转、反复点击同一个词；暂停后的上一句、下一句和进度调整同步更新字幕。手动跳转结束当前连续试听。
- 成片预览返回时读取实际的源视频播放位置，避免依赖整页刷新保存进度。

## 验证（2026-09-19）

使用合成数据和测试视频，没有调用模型或处理用户素材。

| 对比项 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 10,000 句、5,000 处删除的复核生成，中位耗时 | 91.45 ms | 13.62 ms |
| 时间轴末尾同一句内的 6,000 次字幕定位，中位耗时 | 342.41 ms | 0.62 ms |
| 10,000 句页面，同一句内播放约 2.2 秒时的工作台重新渲染 | 118 次 | 0 次 |

前两项为同一机器上七轮合成基准，不含网络、视频解码及页面加载；新旧复核结果逐字段一致。页面对比在 Chrome 中使用本轮修改前的源文件快照和当前版本，各完成一次播放观察；当前句继续逐帧更新，切换句子仍会更新工作台。该场景加载 10,000 句时间轴，仅播放合成视频开头，不代表完整长视频导出性能。

补充覆盖索引边界、重叠与倒序跳转、独立时钟订阅释放、逐字高亮、重复短距离跳转、暂停同步。另在实际页面复测剪前/剪后试听、短句保留、结束试听、复核标记持久化、恢复删除内容、源视频与渲染预览切换，以及桌面和较窄窗口布局。
