# Lina 数字人口播制作工作流

日常制作在 JianyingVideoCut 完成，产品对外显示为 GoldenClip。本机项目位于 `/Users/zhangyang/Projects/JianyingVideoCut`。工作台统一管理口播稿、分镜、素材版本、字幕、复盘与导出，同一条时间线交付 MP4、SRT 和剪映草稿。

本文沉淀 2026-11-19 用户交接的制作约定和历史记录。样片进度与 i9 服务状态以继续制作时的实际检查为准。

## 制作与交付

1. 在「数字人管理」建立或维护数字人档案。新建「数字人口播」项目时，第一页必须选择数字人，自动带入其受众与风格，可临时编辑后创建。旧版未记录主播编号的数字人口播项目继续按 Lina 读取。
2. 核对本次商品资料和可用实拍，记录卖点出处、页码、型号及操作条件。先定完整口播稿，再拆分镜头；商品事实有疑问时，先保留已核实的部分。
3. 按下文的受众和写稿要求起稿，连读全片后同步台词、字幕、逐镜头制作提示词和来源记录。
4. 用 HeyGen 已获授权的 Lina 数字人和克隆声音制作口播。用户采用完整母片方案时，一次生成完整口播，再从同一母片取出镜段和画外音。用户更新数字人后重新核对当前外观及 ID；本轮指定名称为 Lina 的形象，需与带数字编号的外观区分。Lina 本人完成平台授权和声音采样，已有授权与声音以平台实际可用状态为准。
5. 出镜段回传原始有声对口型视频，画外音可引用完整母片中的对应音频区间，也可交接同声独立旁白。B-roll 按 [制作与验收工作流](broll-production-workflow.md) 拆镜并回传，逐镜头保留环境声和动作声的来源记录。
6. 以最终音频确定镜头时长、剪辑点和字幕时间，检查读音、停顿、嘴型、声音连续性及音画对应，再由工作台完成基础成片。默认交付干净画面 MP4 与独立 UTF-8 SRT，不把口播字幕或额外品牌文字烧录进画面。字幕样式由用户最后调整并合成；用户明确确认样式后才制作带字幕成片。剪映草稿里的字幕保留为可编辑文字轨。
7. 完整观看 MP4，检查 SRT，并在实际剪映软件中打开草稿，核对素材、轨道、画幅与音画同步。此前合成素材已用于验证草稿结构，实际剪映打开验收仍待完成。

## Lina 的受众与写稿要求

主要面向中国小学到初中孩子的妈妈，兼顾幼儿园和高中阶段。自然使用「各位妈妈」「你家孩子」；「你家宝宝」用于适合的学龄前场景。

开场优先从上学前准备、放学回家、写作业、亲子阅读或妈妈陪学时自己的需求切入。饮水机先讲给孩子备温水、装水壶；泡茶放在妈妈自己的段落，并承接前文需求。

- 开场聚焦一件事。使用问句时只提一个问题，下一句就给判断或办法；直接给判断的开场也可以使用。
- 按成片顺序连读，每段推进一件新事，避免换一种说法重复开场。可自然用「咱们」「你想」「还有一个」转场，避免堆口头禅。
- 结尾给一个能当场试的小动作。避免套话、夸张营销、未经核实的功效及虚构 Lina 的亲身体验或孩子反馈。
- 涉及热水的镜头由大人操作。

[`presenters.json`](../domains/goldenclip/presenters.json) 保存 Lina 的初始设定，日常修改在「数字人管理」完成。起稿按本项目保存的受众、文字与结构风格，参考 [Lina 短视频结构](../.cursor/skills/lina-short-video-structure/SKILL.md)，初稿完成后按 [口播语气润色](../domains/goldenclip/overlays/lina_spoken_polish.md) 处理台词和字幕。本次明确填写的风格优先于历史建议，保留段序、核心判断及已核实的事实。AI 生成入口为 [`production_planner.py`](../backend/services/production_planner.py)。

## 数字人档案与本次视频设定

入口为 `/presenters`。每位数字人有独立且稳定的编号，可新增、编辑、停用和重新启用。档案包含名称、主要与兼顾受众、观众称呼、内容定位、文字风格、结构风格、口播习惯、画面风格、表达禁忌、补充要求，以及可选的 HeyGen 形象与声音绑定。其他数字人从自己的资料建立风格，不继承 Lina 的结构技能或风格证据。

编辑页按五个大模块展示，并在结构与文字模块的大标题中显示实际 Skill 名称。页面标注与后端加载共用 [`presenter_workflow.json`](../domains/goldenclip/presenter_workflow.json)：

| 模块 | 使用方式与调用时机 |
| --- | --- |
| 基础档案与受众 | 起稿、润色共用的配置，包含名称、称呼、受众与内容定位 |
| 结构风格 | AI 起稿时调用 [`digital-presenter-script-structure`](../.cursor/skills/digital-presenter-script-structure/SKILL.md)；Lina 使用 [`lina-short-video-structure`](../.cursor/skills/lina-short-video-structure/SKILL.md) |
| 文字与口播 | 初稿形成后单独调用 [`digital-presenter-spoken-polish`](../.cursor/skills/digital-presenter-spoken-polish/SKILL.md)，保留结构与事实；Lina 追加专属口播语气规则 |
| 画面、形象与声音 | 分镜规划和镜头提示词读取画面风格，HeyGen 出镜生成读取形象与声音绑定 |
| 表达边界与补充要求 | 起稿与润色共同引用的约束 |

保存档案只保存配置。AI 生成创意按“读取本次档案 → 结构写稿 → 文字润色 → 更新镜头提示词”执行，两个写稿阶段分别调用模型。开始前先加载两个阶段的技能与规则，缺失时在首次模型调用前失败。基础模板不调用模型；用户已保存原稿转分镜也不会重新起稿或润色。

新建数字人口播或编辑现有项目的品牌简报时，可为这一条选「口播目标」。指定商品带货、选购对比、经验分享分别使用对应起稿示例。旧项目和「沿用默认写法」保留原流程。带货起稿先交代指定商品怎样解决开场问题，正文用有依据的场景演示，结尾给行动。不同创意方向可以换切入点，沿用本次选择的口播目标。

选定目标的 AI 起稿同时生成按顺序覆盖口播镜头的段落提纲。润色读取每段的观众问题、回答、镜头和事实依据，并核对前后承接、商品表述和购买顾虑。方向卡的「口播提纲与审查」显示可定位到镜头的待核对项、本次创作目标、两阶段实际提示词的校验值和模型。校验值标识当次固定规则，完整现行规则仍可通过已有规则查看入口读取。程序会检查常见数字规格、商品名和明确权益措辞的前后变化；证据与具体话术是否相符仍由审稿判断。用户保存的定稿可显示商品表述待核对提示，分镜继续使用原稿内容，应用时清除已被替换的创意审查记录。

模块内的可编辑文本框保存数字人的风格设定，不代表 Skill 全文。通过“查看完整 Skill 与规则”按需读取完整文件，保留技能声明、正文与参考资料，支持展开和复制全文。结构阶段另外列出通用生产规则、创作者风格卡和完整证据索引；文字阶段列出通用润色 Skill 与实际配置的专属规则。规则原文为只读内容，不随数字人设定表单写回。

“核对本阶段实际加载的固定规则”与 AI 写稿入口共用组装函数，显示完整固定系统规则。Skill 声明和仅作来源回查的链接不作为执行指令；本次档案、品牌事实及草稿仍作为独立项目资料传入，不把这里的固定规则视为完整模型请求。Skill 文件读取服务器当前内容，项目已有的创作者风格快照则按项目固定版本显示；旧项目尚无快照时明确标为当前版本。

长期档案的用户修改保存在 `backend/data/presenters.json`，不写回源码中的初始目录；可通过 `GOLDENCLIP_PRESENTER_PATH` 指定独立路径。档案按 revision 保存，并拒绝旧版本覆盖。停用保留原档案与既有项目，只从新项目的可选列表中移除。

数字人设定页读取失败时显示重试入口，不把失败当作空档案。读取请求最多等待 15 秒，保存最多等待 60 秒；超时不自动重发保存，需重新读取确认结果。同页切换档案会保留各自的编辑草稿，关闭或刷新页面前提示未保存修改。保存过程中阻止重复提交和切换编辑对象。更换 HeyGen 形象与声音时，后端对完整目录校验设置 35 秒总超时，网络失败返回 502、超时返回 504，档案保持原版本。

保存遇到 409 版本冲突或结果未确认时，可“读取最新档案并保留编辑”：未冲突字段合并到最新版本；同一字段两边都有不同修改时，先逐项选择保留内容，再提交最新 revision。名称、观众称呼及补充要求的长度和条数在提交前检查。档案文件无法读取或写入时，接口返回 503 和可恢复提示，不覆盖原文件。

创建数字人口播项目必须提交 `presenter_id`。`presenter_overrides` 是可选的完整本次配置，省略时使用档案默认值；`presenter_revision` 可防止用户仍在查看旧档案时创建。项目保存 `presenter_snapshot` 与创建当时可用的 `presenter_style_snapshot`，之后编辑长期档案不会改变已有视频。首次编辑旧版共享档案时，先为尚无副本的关联项目固定旧设定和原有 Lina 声音绑定，不改现有台词和素材。

项目「本次数字人设定」可继续临时编辑。更新会让未使用的旧创意失效，并要求复核已有分镜；保留当前台词和素材。正在生成时拒绝修改。新一轮 AI 写稿使用项目副本，生成方向另外保存实际输入的 `presenter_snapshot` 和 `style_snapshot`；已保存口播转分镜仍保留原文字句和顺序。

形象和声音须同时选择或同时留空；绑定不包含 API Key。新项目使用自己的绑定，未绑定的数字人不会沿用其他人的形象和声音。旧版 Lina 项目在固定副本前兼容原共享设置。项目开场中的 HeyGen 设置保存后，绑定只更新当前视频；长期档案需在管理页单独修改。读取目录和保存配置不生成付费媒体。

| API | 行为 |
| --- | --- |

## 片长与素材入出点

「数字人口播」参考片长可以留空，按内容决定长度。1 分半到 2 分钟可以做，讲清楚也可以更短，不设统一时长上限。开场预计约 5 秒只是分镜安排，实际以生成后自然说完一句为准，不能为了凑秒数截断台词或强行加速。

工作台的「入点／出点」表示所选素材的截取范围，不是待生成文案的时间。口播稿可先写好，视频回传或选中后才显示素材时间。

## 分幕工作台

数字人口播项目已有分镜时，「创意与镜头」使用分幕目录、当前幕预览和编辑区。左侧按已保存的分镜顺序展示缩略图、标题、选段时长和状态，可筛选待处理幕；选择目录或上一幕、下一幕切换当前幕。界面上的幕对应现有 `shots`，不改变镜头编号或排序。

右侧「文案」「画面」「声音」分别容纳台词与镜头修改、视频回传及选段、独立旁白回传及选段；同幕切换页签保留尚未应用的选段。完整口播稿、创意方向、素材库和本次数字人设定通过顶部工具入口打开。每幕仍需检查画面与声音，并使用原有标记可用操作。

文案、选段、完整口播稿或人设有未保存修改时，切幕或离开当前工具前提示继续编辑或放弃修改。保存失败保留输入；只保存画面或旁白的一项时，不清除另一项尚未保存的修改。

预览只挂载当前幕的视频，限制在已保存的画面入出点内。独立旁白模式静音画面原声，并同步播放所选旁白区间；原声或生成对白模式播放视频原音，静音模式不播放对白。预览未执行成片阶段的停顿收紧、字幕或混音处理，选段合计不代表最终导出时长。

导航通过 `GET /api/productions/{project_id}/assets/{asset_id}/thumbnail?t=秒` 获取当前选段内的 JPEG，不复用整条母片的统一封面。接口只读取本项目的视频，要求 `0 <= t < 素材时长`；在项目私有目录缓存缩略图，不修改项目 revision。非法素材或时间返回 422，素材不属于项目或文件不存在返回 404，缺少 FFmpeg 返回 503，生成超时返回 504。失败时目录仍显示标题和状态。
